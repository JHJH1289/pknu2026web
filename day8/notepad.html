홈 기능 문의

할 일 관리와 채팅을 한 화면에서

랜딩 페이지는 투두리스트 중심으로 보여주고, 필요할 때만 모달 채팅창을 띄우는 구조입니다. 깔끔한 첫 화면과 대화형 UI를 같이 가져갈 수 있습니다.

오늘의 할 일

간단한 투두리스트 예제입니다.

  • HTML 구조 잡기
  • CSS 스타일링 적용
  • 모달 채팅창 연결

간단한 구성

HTML, CSS, JavaScript만으로도 랜딩 페이지와 모달 채팅창을 함께 만들 수 있습니다.

직관적인 사용

메인 화면에서는 할 일을 관리하고, 버튼을 누르면 대화창이 바로 열립니다.

확장 쉬움

나중에 로그인, 알림, 로컬스토리지 저장 같은 기능도 쉽게 붙일 수 있습니다.
